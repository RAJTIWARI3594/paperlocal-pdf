# Contributing

Keep processing client-side and avoid analytics, upload APIs, runtime CDNs or credential requirements. Use invented fixtures, never real private documents. Run core and browser checks after changes, inspect the downloaded PDFs, and update validation notes honestly. Maintain keyboard operation, focus indicators, reduced-motion handling and mobile layout. Retain third-party licenses and document reviewed version upgrades. Security guarantees and new conversion claims need actual evidence, not marketing copy.

A useful report includes the browser/version, tool, exact steps, expected outcome and a small synthetic PDF/image that demonstrates the issue. Never attach confidential originals.
